# Теплоблок — лендинг (сайт-визитка)

Премиальный одностраничный сайт для продажи теплоблока из природной вулканической породы.
Регион работы: **Краснодарский край и Республика Адыгея**. Сделан под запуск рекламы в **Яндекс.Директ**.

Стек: чистые **HTML + CSS + JS**, без сборки и зависимостей. Открывается двойным кликом по `index.html`.

---

## 📁 Структура

```
site/
├── index.html        ← главная страница (весь контент)
├── privacy.html      ← политика конфиденциальности (нужна для Директа)
├── styles.css        ← все стили
├── script.js         ← вся анимация и логика
├── assets/img/       ← фотографии продукции
└── README.md         ← этот файл
```

## 📨 ПОДКЛЮЧЕНИЕ ФОРМ (заявки)

Сейчас формы **имитируют** успешную отправку (показывают «Заявка отправлена»), но никуда не шлют —
это демо. Перед рекламой нужно подключить реальную доставку заявок. Варианты:

1. **Telegram-бот** (быстро, бесплатно) — заявка падает в личку/чат.
2. **Formspree / Getform** — заявка приходит на e-mail, без своего сервера.
3. **CRM / Битрикс24 / amoCRM** — если будет отдел продаж.

Точка для подключения — функция `sendLead()` в `script.js` (помечена комментарием `TODO`).
Скажете, какой вариант удобнее — настрою.

## 🚀 КАК ОПУБЛИКОВАТЬ (когда купите домен)

Сайт статический, поэтому хостинг — копеечный или бесплатный:

- **Бесплатно:** Cloudflare Pages, Netlify, GitHub Pages, Vercel — просто загрузить папку.
- **Обычный хостинг (reg.ru, timeweb, beget):** закинуть содержимое папки `site/` в `public_html`.

После покупки домена: привязать домен → загрузить файлы → подключить **Яндекс.Метрику** (нужна для Директа) → отправить на модерацию.

## 🛡️ ЧЕК-ЛИСТ ДЛЯ ЯНДЕКС.ДИРЕКТА (чтобы не словить бан)

Сайт уже учитывает требования модерации. Перед запуском проверьте:

- [x] Понятно, что и кому продаётся (теплоблок, регион, цена «от»)
- [x] Посадочная релевантна объявлениям (заголовки/тексты про теплоблок)
- [x] **Политика конфиденциальности** есть (`privacy.html`) и на неё ведут ссылки
- [x] На формах — **чекбокс согласия** на обработку ПДн со ссылкой на политику
- [x] Cookie-уведомление есть
- [x] Адаптив под телефон (большинство трафика — мобильный)
- [ ] **Заполнить реквизиты юрлица/ИП** (без них модерация придирается) ← обязательно
- [ ] **Указать реальный телефон и контакты**
- [ ] Подключить **Яндекс.Метрику** + цель на отправку формы
- [ ] Проверить, что формы реально доставляют заявки

⚠️ Юридический момент: характеристики в текстах («морозостойкость 25 циклов», «водопоглощение 11%»,
«срок службы ×8») должны подтверждаться вашими документами/испытаниями — держите сертификаты под рукой,
модерация и ФАС могут запросить обоснование. Цены и сравнения даны аккуратно, с оговоркой в сноске.

## ✏️ Как поменять цвет/контент

- Цвета и отступы — в самом верху `styles.css` (блок `:root`, переменная `--accent` — акцентный цвет).
- Тексты — прямо в `index.html`, всё на русском, секции подписаны комментариями.
- Фото — заменить файлы в `assets/img/` (имена оставить те же — тогда ничего не сломается).
